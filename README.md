# Ретро открытий пиццерий

GitHub Pages отдаёт интерфейс отчёта. Выручка, имена партнёров и комментарии загружаются в браузер из вкладки «Сводная» при открытии отчёта из Google Таблицы. Кнопка «Обновить данные» перечитывает вкладку с текущими фильтрами, месяцем и сортировкой.

## Публикация

1. Создайте репозиторий `dleonov-eng/pizzeria-openings-retro` и загрузите в ветку `main` папки `docs` и `apps-script` из архива.
2. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch → main → /docs → Save**.
3. После сборки откройте адрес ниже. Страница предложит перейти в исходную таблицу.

https://dleonov-eng.github.io/pizzeria-openings-retro/

## Подключение таблицы

1. Откройте [исходную Google Таблицу](https://docs.google.com/spreadsheets/d/1XT382mmH0xkTwaAqO0on7GSnPfrHFnE443TFUKiCGLY/edit) с правами редактора и выберите **Расширения → Apps Script**.
2. Вставьте содержимое `apps-script/Code.gs` в файл скрипта. Если вы уже вставили предыдущую версию скрипта «Ретро», замените её целиком. Если в проекте есть другой код, сохраните его. В проекте с существующей функцией `onOpen` добавьте в неё вызов `addRetroMenu_();`, пропустив второе определение `onOpen`.
3. Сохраните проект, обновите вкладку с таблицей и выберите **Ретро → Открыть лендинг**. При первом запуске подтвердите разрешение для текущего документа. Интерфейс загрузится с Pages в окне таблицы. Этот способ открытия рассчитан на редакторов таблицы.
4. Чтобы проверить подключение после изменения строки в «Сводной», нажмите **Обновить данные** в отчёте и сверьте значение для этой пиццерии.

Скрипт проверяет идентификатор таблицы и читает диапазон A:AN вкладки «Сводная». Публичная страница содержит заголовки столбцов. Строки отчёта передаются из открытой таблицы в окно отчёта в браузере пользователя.
