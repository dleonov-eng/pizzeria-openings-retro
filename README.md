# Ретро открытий пиццерий

При открытии лендинга по прямой ссылке нажмите **Войти через Google**, выберите аккаунт с доступом к таблице и подтвердите выбор «Ретро. Открытия». После возврата на лендинг браузер считывает вкладку «Сводная» с правами этого пользователя. Кнопка «Обновить данные» перечитывает вкладку с текущими фильтрами, месяцем и сортировкой.

## Публикация

1. Создайте репозиторий `dleonov-eng/pizzeria-openings-retro` и загрузите в ветку `main` папки `docs` и `apps-script` из архива.
2. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch → main → /docs → Save**.
3. После сборки откройте адрес ниже.

https://dleonov-eng.github.io/pizzeria-openings-retro/

## Настройка входа для прямой ссылки

1. В проекте Google Cloud включите [Google Sheets API](https://console.cloud.google.com/apis/library/sheets.googleapis.com) и [Google Picker API](https://console.cloud.google.com/apis/library/picker.googleapis.com).
2. В Google Auth Platform настройте аудиторию для пользователей отчёта. Для внешнего приложения в режиме Testing добавьте тестовые аккаунты. В Data Access добавьте разрешение `https://www.googleapis.com/auth/drive.file`. Оно относится к выбранному пользователем файлу. Отчёт выполняет запрос на чтение диапазона «Сводная»!A:AN.
3. [Создайте OAuth-клиент](https://console.cloud.google.com/auth/clients) типа **Web application**. В **Authorized redirect URIs** укажите точный адрес страницы, включая последний слеш: `https://dleonov-eng.github.io/pizzeria-openings-retro/`.
4. Укажите публичный Client ID в константе `clientId` в `docs/index.html` и опубликуйте изменение. Секрет клиента для этого браузерного потока не нужен.
5. Проверьте прямую ссылку сначала с аккаунтом с доступом к таблице, затем с аккаунтом без доступа. При успешном входе на странице появятся строки «Сводной». Если Google откажет в чтении, отчёт скроет загруженные строки и предложит вход.

Google Picker получает идентификатор одной таблицы. Google Sheets API проверяет доступ при каждом чтении. Браузер хранит токен только в памяти страницы. Повторное открытие вкладки требует входа.

## Открытие внутри таблицы

1. Откройте [исходную Google Таблицу](https://docs.google.com/spreadsheets/d/1XT382mmH0xkTwaAqO0on7GSnPfrHFnE443TFUKiCGLY/edit) с правами редактора и выберите **Расширения → Apps Script**.
2. Вставьте содержимое `apps-script/Code.gs` в файл скрипта. Если вы уже вставили предыдущую версию скрипта «Ретро», замените её целиком. Если в проекте есть другой код, сохраните его. В проекте с существующей функцией `onOpen` добавьте в неё вызов `addRetroMenu_();`, пропустив второе определение `onOpen`.
3. Сохраните проект, обновите вкладку с таблицей и выберите **Ретро → Открыть лендинг**. При первом запуске подтвердите разрешение для текущего документа. Интерфейс загрузится с Pages в окне таблицы. Этот способ открытия рассчитан на редакторов таблицы.
4. Чтобы проверить подключение после изменения строки в «Сводной», нажмите **Обновить данные** в отчёте и сверьте значение для этой пиццерии.

Скрипт проверяет идентификатор таблицы и читает диапазон A:AN вкладки «Сводная». Публичная страница содержит заголовки столбцов. Строки отчёта передаются из открытой таблицы в окно отчёта в браузере пользователя.
